A Node 22 program that hands make.fun the address of one X post: it copies `POST.json` from the repository root to `/output`. The post itself is the entry — a quote of make.fun's make-your-own-bounty post, with a photo, @makefunai, and play code `cc7tcnw6`. Places go by replies + reposts + quotes; the top 50 share $250.

## Run it

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
